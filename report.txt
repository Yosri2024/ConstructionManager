  CONSTRUCTION MANAGER - PROJECT REPORT
  Construction Site Management Web Application
================================================================

WHAT THIS IS
------------
A self-hosted PHP web application for managing construction
sites, the workers assigned to them, and the day-to-day
operations that happen on each site.

It is designed to be run on a local WAMP/MAMP/LAMP stack and
is intended for small-to-medium construction firms that need
one tool to keep track of:

  - Who works where
  - How many hours each worker logs
  - Whether each site is active, paused, or done
  - Daily progress reports filed by supervisors
  - Workers who need to be transferred between sites

The app has two user roles:

  - manager     -> full control: create sites, workers, users
  - supervisor  -> field user: mark attendance, log hours, file
                  daily reports, request worker transfers

================================================================
HOW TO RUN IT
================================================================

1. Install WAMP (or any Apache + MySQL + PHP 7.4+ stack).

2. Copy the project folder into Apache's document root.
   Default WAMP path:  D:\wamp64\www\ConstructionManager\

3. Start WAMP, make sure the icon is green (Apache + MySQL up).

4. Open a browser and visit:

       http://localhost/ConstructionManager/

5. The app will auto-create the SQLite database on first visit.
   If you want MySQL instead, import database_mysql.sql via
   phpMyAdmin, then update config.php ($DB_TYPE = 'mysql').

6. Default login (change immediately after first login):
       username: admin
       password: admin123

================================================================
FEATURES - WHAT EACH PAGE DOES
================================================================

LOGIN / LOGOUT
  - login.php   : username + password authentication
  - logout.php  : destroys session, returns to login

DASHBOARD (dashboard.php)
  - At-a-glance summary: total sites, workers, hours this week,
    pending transfer requests, recent daily reports
  - Quick-action buttons to add new Job/Site/Worker, log hours,
    or file a report

JOBS / PROJECTS (jobs.php)
  - High-level "project" entity (e.g. "Highway 17 Bridge")
  - Each job has a code, name, description, client, budget,
    and status (active/paused/done)
  - One job can have many sites under it

SITES (sites.php)
  - The actual physical construction locations
  - Each site is linked to a job and to a primary supervisor
  - Many supervisors can be assigned to a single site
  - Status: active, paused (with a reason), or done
  - Filter by site name, job code, or status
  - "+ New Site" button (top right) opens the create form

SITE DETAIL (site_detail.php)
  - One page per site
  - Shows: address, supervisors, status, recent daily reports
  - Quick link to file a new daily report for this site

WORKERS (workers.php)
  - Manage the roster of construction workers
  - Each worker has a name, status (active/inactive), and
    a current site assignment
  - Removing a worker unlinks them from their current site

ATTENDANCE (attendance.php)
  - Daily presence tracker (Present / Late / Absent / Sick /
    On Leave) per worker per site
  - Supervisors mark attendance for their own sites only
  - Managers see the full picture and can edit any record
  - Polls every few seconds for fresh counts on the dashboard

WORK HOURS (hours.php)
  - Supervisors log how many hours each worker worked, on
    which site, and on which date
  - Filter by site, worker, job code, or date range
  - Auto-fills worker list based on selected site
  - Hours roll up to dashboard and site totals

DAILY REPORTS (reports.php / report_view.php)
  - Free-form end-of-day progress reports filed by supervisors
  - Each report covers one site, one date, and contains a
    narrative + optional notes (weather, blockers, etc.)
  - Managers can view all reports, supervisors only their own
  - View report in full via report_view.php

ASSIGNMENTS (assignments.php)
  - Track which worker is assigned to which site, and for how
    long (start date -> optional end date)
  - One worker can be assigned to one site at a time
  - "+ New Assignment" creates a new assignment period

AVAILABLE WORKERS (available_workers.php)
  - Workers currently at a site you do NOT manage
  - Supervisors can request a transfer; manager approves later

TRANSFER REQUESTS (transfer_requests.php)
  - Manager-only inbox of pending transfer requests
  - Approve -> worker is moved to the requesting site
  - Reject -> request closed, no change
  - Sidebar shows live count of pending requests

PLANNING (planning.php)
  - Bird's-eye calendar of who is assigned to which site and
    for what window
  - Managers can create new assignments from here

USERS (users.php)
  - Manager-only: add/remove/edit users
  - Cannot delete yourself
  - Cannot delete the last manager (safety)

DATA MODEL OVERVIEW
================================================================

DAILY WORKFLOW (suggested)
================================================================

Morning (supervisor):
  1. Log in
  2. Go to Attendance -> mark each worker Present / Late / Sick
  3. Update assignments if anyone is starting or ending today

During the day (supervisor):
  4. Hours -> log partial hours as the day progresses

End of day (supervisor):
  5. Reports -> file a Daily Report for the site
  6. Available Workers -> if you need someone from another site,
     submit a Transfer Request with a clear reason

As needed (manager):
  7. Transfer Requests -> approve or reject pending moves
  8. Sites / Jobs / Workers -> create new records as projects
     start and crew changes
  9. Dashboard -> check weekly hours, pending requests, recent
     reports

================================================================
TROUBLESHOOTING
================================================================

"Database is locked"
  -> Stop WAMP, delete construction.db, restart WAMP, reload
     the page. The schema will be re-created.

"Access denied" on every action
  -> Your session expired. Log in again.

Sidebar shows "Transfer Requests" but the page is empty
  -> Only managers can act on transfer requests. Supervisors
     see the page read-only.

Changes not appearing
  -> Hard refresh the browser (Ctrl+Shift+R) to bypass cache.
